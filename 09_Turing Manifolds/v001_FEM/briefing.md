# Research Briefing: № 09 — Turing Manifolds [v001: FEM]
> Path: **Finite Element Method (Mesh)**

## 1. Approach
Solves the Reaction-Diffusion equations on a fixed triangle mesh. Utilizes the Laplace-Beltrami operator for surface diffusion.

## 2. Implementation
- **Solvers:** Implicit/Explicit integration using mesh adjacency.
- **Visuals:** Patterns mapped directly to vertex data or UV textures.

## 3. Design Reference
Consistent with **№ 02 — Gas Giant (S² FLIP)**.
