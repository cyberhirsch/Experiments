# Research Briefing: № 09 — Turing Manifolds [v002: Local Neighborhood]
> Path: **Meshless / Point Cloud (Local Sampling)**

## 1. Approach
Diffusion is calculated between unstructured points in space. Allows for dynamic surfaces or point clouds without fixed connectivity.

## 2. Implementation
- **Solvers:** K-Nearest Neighbors (KNN) or radius-based local averaging.
- **Visuals:** Organic patterns on point clouds or implicit surfaces (metaballs).

## 3. Design Reference
Consistent with **№ 02 — Gas Giant (S² FLIP)**.
