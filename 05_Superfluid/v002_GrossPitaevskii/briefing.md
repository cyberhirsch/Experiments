# Research Briefing: № 05 — Superfluid [v002: Gross-Pitaevskii]
> Path: **Nonlinear Schrödinger / Gross-Pitaevskii (Spectral)**

## 1. Approach
This version uses the Gross-Pitaevskii Equation (GPE) for a more accurate quantum fluid description. It is non-dissipative and preserves the wave function's norm.

## 2. Implementation
- **Solvers:** Split-Step Fourier Method (Pseudo-spectral). Requires high-performance FFT.
- **Visuals:** Probability density isosurfaces and quantum phase interference patterns.
